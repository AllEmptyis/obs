# 마스터 노드 crash 및 머신타입 미지원
- 호스트 oom 발생으로 인해 마스터 노드 종료, 재부팅 하려고 하니 머신 타입 지원 안함 메시지 출력
```
[root@localhost qemu]# virsh start kuber
오류: 도메인 'kuber'를 시작하는데 실패히였습니다
오류: 지원되지 않는 설정: 에뮬레이터 '/usr/libexec/qemu-kvm'가 장비 유형 'pc-q35-rhel9.6.0'을 지원하지 않습니다
```
- 원인 - 모름
- 다른 VM과 타입 비교
	- 원인은 모르지만 다른 타입 사용 중
```
[root@localhost qemu]# virsh dumpxml kuber | grep -n "<type"
13:    <type arch='x86_64' machine='pc-q35-rhel9.6.0'>hvm</type>

[root@localhost qemu]# virsh dumpxml TiController | grep -n "<type"
11:    <type arch='x86_64' machine='pc-i440fx-rhel7.6.0'>hvm</type>

[root@localhost qemu]# virsh dumpxml worker151 | grep -n "<type"
16:    <type arch='x86_64' machine='pc-q35-rhel9.2.0'>hvm</type>
```
## 해결
- virsh edit kuber
- 머신 타입을 위 워커노드에서 지원하는 `pc-q35-rhel9.2.0` 로 변경
