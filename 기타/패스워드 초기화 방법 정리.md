# BCM
## 기본 초기화 방법
- 부트모드 진입 후 아래 명령어 입력 (부팅 시 !!! 연타)
	- 적용 버전: **v3.0.8.10.0 / BL 6.3**
```
setenv default_passwd yes
run bootcmd
saveenv // 해당 명령어는 디폴트pw로 로그인 하도록 하는 기능 설정 영구 저장

-> default_passwd 값을 yes로 변경 시 default pw (root/admin) 으로 로그인 가능
```
## 초기화 안 되는 경우
- default_passwd=yes 값을 변수에 설정하여 부팅
	- case 250425-005 참고 (CS2728GP)
```
부트모드 진입 후 아래 명령어 입력

setenv setbootargs 'setenv bootargs default_passwd=yes console=ttyS0,9600n8 maxcpus=1 mem=496M loglevel=3 log_buf_len=1M currentplos=$currplos configplos=$firstos'

printenv // 위 설정값이 제대로 저장되었는지 확인

run bootcmd
```

- 대상장비
	-  TiFRONT-CS3832GXE, CS3852GXE, CS2628GXPR
