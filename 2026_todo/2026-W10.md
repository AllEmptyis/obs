```
timatrix 실습 정리
- 포트 스캔, 플러딩은 둘 다 탐지/차단으로 되어 있으면 포트 스캔이 먼저 탐지
  포트 스캔이 꺼져 있으면 플러딩으로 탐지/차단 됨
- 뭔가 오류로 인해 둘 다 탐지된 적도 있었음
  
예외 설정
- 탐지될 규칙에 대해 따로 따로 예외 처리 필요함
  예를 들어 동일한 dip 에 대해서도
  포트 스캔 > 포트 지정해서 규칙 추가
  플러딩 > 포트 지정하지 않고 규칙 추가
  필요
  
  목적지 192.168.212.1/32 포트 any 허용 > 포트 스캔 미탐지
  목적지 192.168.212.1/32 포트 80 허용 > 플러딩 미탐지
```

```
snmp 실습 정리
snmp v2: 커뮤니티 스트링(평문)만 지원
snmp v3: 인증(auth), 암호화 둘 다 지원
mib browser > advanced > snmp v3 > 시큐리티 레벨 auth, priv 둘 다 선택
컨트롤러 서비스/제어 장치 설정에서 snmp on 했는지 확인

snmp 트랩 커뮤니티: 연동될 nms 서버에서 사용하는 커뮤니티 (아무거나 지정)
agent ip: 스위치 ip
trap-auth: 인증 실패했을 때 트랩
trap-traffic: 트래픽 관련 이벤트 생겼을 때 트랩
trap server ip: 연동 될 nms 서버 ip 지정
//현재 테스트를 위해 자기자신 pc ip로 설정
인증 실패 후 와이어샤크로 트랩 확인 가능, 
snmpv2 사용 시 커뮤니티가 스트링으로 오는 것 확인 가능
trap port: 모니터링 할 포트 지정

+inform: nms가 트랩 받은 뒤 수신 확인을 전송
```
