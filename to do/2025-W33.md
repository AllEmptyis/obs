LS엠스톤
로그 의미 정리
UPS: 정전,전원 이상 시에도 일정 시간 동안 전력을 공급하는 장치
UPS연동: 서버를 UPS와 연동해두면 배터리,전원차단여부 등을 모니터링 하며 필요 시 자동으로 안전종료 수행
UPS연동(전원) 의미: UPS로부터 신호를 받아서 재부팅 되었을 가능성

journalctl: systemd-journald가 수집한 시스템 로그를 조회하는 명령어 (바이너리 포맷)
커널 메시지, 서비스로그, 시스템 부팅/종료, 하드웨어 이벤트 등

journalctl -b -1: -b는 특정 부팅 시점의 로그를 조회, -1은 이전 부팅 때의 로그 조회

/etc/crontab: 시스템 전체에 적용되는 cron 작업 설정파일
/etc/cron.*/*: `/etc/cron.daily`, `/etc/cron.hourly` 등 주기별로 실행되는 스크립트 저장 경로
/var/spool/cron/: 사용자별로 등록한 개인 cron 작업 목록

/var/log/messages: rsyslog/syslog 데몬이 수집하는 텍스트 기반 로그 파일
커널 메시지, 서비스 상태, 시스템 이벤트 등이 기록
jouranlctl 메시지에 비해 필터링, 부팅시점 단위 구분이 어려움

last(명령어): `/var/log/wtmp` 파일을 읽어서 로그인/로그아웃, 재부팅 기록 출력
last -F: 시간을 포맷으로 출력
last -x: 로그인 로그 + 재부팅/종료/런레벨 변경 로그 출력

Kdump: 커널패닉 발생 시 현재 시스템 메모리 내용을 덤프해서 저장하는 기능
/var/crash : kdump 파일 저장 경로
