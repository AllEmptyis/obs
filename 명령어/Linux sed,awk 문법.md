# sed (stream editor)
- 간단한 편집 명령 (텍스트 치환,삭제,출력)을 스트림 단위로 실행하는 도구
	- 스트림: 데이터를 순차적으로 처리 (전체 로딩하지 않고 실시간으로 처리)
- 패턴 매칭 > 치환/편집 > 출력
- 명령 구조
```
sed [옵션] '주소 범위 동작' 파일
```
- 옵션: -n
	- 모든 라인을 출력하지 않고, p(print) 명령이 있는 라인만 출력하도록 함
- 주소 범위: `/패턴1/,/패턴2/`
```
/패턴1/: 시작 조건 (패턴이 매치된 라인부터)
/패턴2/: 끝 조건 (해당 패턴이 매치된 라인까지)
, :  범위를 나타내는 구분자
$ : 파일의 끝 (특수 주소)
```
- 동작: p (print)
