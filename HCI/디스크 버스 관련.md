# PCI / PCIe
- PCIe는 CPU와 pcle 슬롯에 연결된 카드 간 통신할 수 있도록 해주는 역할
	- 범용 데이터 버스(통로)
- PCIe 슬롯에는 gpu, NIC, 디스크(sata controller) 등 여러가지가 꽂힐 수 있음
- PCI는 구형 (병렬) 방식, PCle는 직렬 방식으로 cpu와 각 카드가 각각 직렬로 통신함
- OS(cpu)-PCIe 슬롯 - 카드 간에는 TLS 라는 프로토콜에 SCSI 명령어를 실어서 통신함

- HBA (Host Bus Adapter)
	- PCle 슬롯에 꽂히는 물리적 카드
	- 서버가 디스크와 통신할 때 포트가 부족한 경우 확장해주는 용도

# SCSI (Small Computer System Interface)
- usb, cd rom 등이 os와 통신하기 위한 명령어
- 실제 SCSI 명령어를 사용하는 것
```
- 테이프 드라이브 (백업 장비)
- CD-ROM/DVD 드라이브 — IDE 케이블에 물려있어도 **ATAPI**(ATA Packet Interface)라는 방식으로 SCSI 명령을 그대로 포장해서 씀 (앞서 얘기했던 그 부분이에요)
- USB 저장장치 — USB Mass Storage 규격 자체가 SCSI 명령을 그대로 씀
- SAS 디스크 — 네이티브로 SCSI
- 옛날 스캐너, 프린터도 SCSI로 붙던 시절이 있었음
- iSCSI — 아예 이름 그대로 "IP 네트워크로 SCSI를 실어 나르자"는 규격
```

- SCSI도 기존에는 물리 커넥터, 규격, 그리고 명령어 였으나 현재 명령어를 제외하고는 거의 단종됨
# SATA (Serial ATA)
- ata라는 명령을 시리얼 방식으로 보내는 규격
	- ATA는 디스크가 OS와 통신하기 위한 명령어
- SATA 컨트롤러와 디스크 사이의 통신을 위한 하드웨어 규격
	- IDE(PATA): 병렬 방식, 옛날
	- SATA: 직렬 방식
- 디스크는 ATA 명령을 사용해서 통신함, 그래서 기존에는 ata를 사용해서 OS와 디스크가 통신했으나,
  SCSI가 좀 더 기능이 좋아서 리눅스에 `libata` 라는 드라이버를 만들어서 ata를 scsi로 변환하는 방식으로 사용하게 됨
  즉, 번역 동작은 OS 드라이버에서 수행됨

- SATA Controller: ATA 명령을 실제 전기신호로 만들어서 보내주는 컨트롤러
